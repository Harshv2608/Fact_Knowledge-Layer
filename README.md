# Fact Knowledge Layer

A knowledge layer over documents for the engineering internship hiring assignment. This system extracts meaningful numerical or semantic facts from PDFs, links them to exact evidence, and performs cross-document reasoning to identify whether facts corroborate, contradict, or can be reconciled through context.
